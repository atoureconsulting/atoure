# Demos

What we show a prospect before they sign: a deck and a sample report that
look like the real thing, with fictional figures.

## What exists

Both are combat sports, built in October 2026.

| Demo | Deck | Sample report |
|---|---|---|
| PFL Africa, Kigali | `customers/pfl-africa/deck.pdf` | `customers/pfl-africa/sample-report.html` |
| African MMA League, Abidjan | `customers/african-mma-league/deck.pdf` | `customers/african-mma-league/sample-report.html` |

Live versions are linked in `customers/README.md`. Both stay in
`customers/` because each carries that client's logo. Never send either to a
different prospect.

## What is missing

The current goal is new sectors, and there is no demo outside combat sports.
Build these in order (see `ROADMAP.md`):

1. A West African music festival. Lead with sponsor activation and diaspora
   reach.
2. A tourism board campaign, paired with the Programs Menu in the website
   repo.
3. A conference or trade fair.

Each new demo gets its own folder here, for example `demos/festival/`, with a
deck source and a sample report. Use an invented event name, not a real
prospect's logo, so the demo can go to anyone in that sector.

## Rules

- Page one of every sample report says in red that every creator and figure
  is fictional.
- Totals stay consistent from post to creator to summary, so the demo
  survives a close read.
- Creator handles are invented. Never put a real creator's name on
  fictional figures.
