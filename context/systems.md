# Systems

Where AToure's work lives, and what an AI employee may do in each. The full
delegation rules are in `PERMISSIONS.md`.

| System | What it is | AI employees may |
|---|---|---|
| `atoure` repo | This workspace | Read; write on a branch; open a pull request |
| `website` repo | The public site, atoureconsulting.com, plus hosted proposals and tour pages | Read; change on a branch with a pull request. Never push to main: main is live |
| `CRM` repo | Contact manager on Cloudflare Pages, backed by a Google Sheet ("Contacts" tab) | Read the code; change on a branch. Never write to the live sheet |
| `atoure-talent-database` repo | The creator roster site and admin tool, backed by a Google Sheet ("Updated Oct 2026" tab) | Read; change on a branch. Never write to the live sheet |
| Gmail | Baba's inbox | Read and search; create drafts. Never send, reply, forward or delete |
| Google Drive | Baba's files | Read and search. Never share, move or delete |
| Instagram and ad accounts (Windsor) | Analytics and posting | Read analytics. Never post, comment or change a campaign |
| Higgsfield, Canva | Image, video and design tools | Ask Baba first: generation spends credits |
