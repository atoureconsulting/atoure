# The Talent We Can Offer

Talent access is the first layer of the Creator Visibility Offer and the core
of every government programme. This is what the network looks like. The
live roster is the source of truth; this page is a summary from October
2026.

## Where it lives

- **Live roster:** the Google Sheet tab "Updated Oct 2026", read by the
  `atoure-talent-database` site through Apps Script. The public roster page
  and the admin page both read it.
- **Photos:** `Photos/` in the `atoure-talent-database` repo.
- **Never write to the live sheet.** Suggest changes to Baba instead.

## Shape of the roster

About 105 creators and artists.

Mostly content creators, with artists, presenters, athletes and comedians.

## Global names

Ashton Hall, plus the IShowSpeed relationships. Check the roster for current
follower figures before quoting any number: the roster's last updated date
tells you how fresh it is.

## Fields that matter when matching talent

`country`, `tier`, `category`, the follower counts per platform,
`business_email`, `outreach_status`, `notes` and `last_updated`.

## Rules

- Match creators to the audience the client needs, not to follower count
  alone (`offers/creator-visibility-offer/adapting-by-event-type.md`).
- Include one creator from each target market.
- Never promise a creator's availability or fee. Baba confirms both.
- Only creators on the roster are "AToure creators". Anyone else is a
  creator we would approach.
