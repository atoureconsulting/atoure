# Instagram working files

The Instagram skills (`.claude/skills/ig-*`) normally keep their files in a
hidden folder on one computer (`~/.instagram-agent/`). For AToure they live
here instead, so cloud and local sessions share them. `CLAUDE.md` tells
Claude to read and write this folder.

| File | Written by | What it holds |
|---|---|---|
| `voice.md` | You, once (filled in from the offer; confirm the marked lines) | Who AToure talks to, how it sounds, positions, what is off limits, proof it can use |
| `swipe.md` | `ig-viral` (niche research) | Reels that beat their accounts' usual numbers, with the hook formula each used |
| `log.md` | `ig-reel`, `ig-comment` and others | What was made, posted and commented on, so later skills can learn from it |

Nothing here is published by itself. Drafts still go to BrightBean for your
approval.
