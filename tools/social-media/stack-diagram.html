How the social stack connects

One loop for Instagram, LinkedIn and atoureconsulting.com. Claude runs each step from the AToure folder, and the repository's CLAUDE.md tells it which tool does which job.

By channel

Instagram

@atoure.management
Plan
Reels, carousels and stories from atoure-social, with hooks scored before filming
Make
Design Engine or Canva for images; Lemo-Opuscar, Higgsfield or event footage for reels
Publish
Windsor.ai now; BrightBean once connected
Measure
Windsor.ai insights, then BrightBean analytics

LinkedIn

Company page and founder
Plan
Posts, document carousels and short video from atoure-social, led by proof and insight
Make
Design Engine for carousel slides and covers; Lemo-Opuscar for explainers
Publish
BrightBean, for the company page and the founder's profile
Measure
BrightBean analytics, then a post-mortem

Website

atoureconsulting.com
Plan
One article or case study a month, written as the base for LinkedIn and Instagram pieces
Make
Impeccable to review and improve pages; Design Engine for hero images
Search
The marketing SEO audit skill
Measure
Google Analytics 4 and Search Console through Windsor.ai, once connected

Can it help the website? Yes, for content, design, search and checks. None of these tools hosts the site, so changes go live through the site's code or its host account.

Ready now

  • atoure-social: AToure's own content skill
  • Design Engine, set to the AToure brand
  • Impeccable and Lemo-Opuscar plugins
  • Higgsfield, Canva and Windsor.ai (Instagram linked)
  • Marketing and brand-voice skills

Needs you

  1. Create a free BrightBean Studio account and connect Instagram and LinkedIn.
  2. Add it at claude.ai/customize/connectors as a custom connector: https://studio.brightbean.xyz/api/v1/mcp
  3. On your computer, run npm install once in .claude/skills/design-engine/scripts.
  4. Optional: connect Google Analytics 4 and Search Console in Windsor.ai.
