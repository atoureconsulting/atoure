# Routine: Post Event Report

Who: Reporting analyst.
When: Starts before a client event and runs to day 14 after it.

This routine follows an event, not the calendar. When a client event is
confirmed, ask Claude to schedule one reminder each for day 1, day 2, day 7
and day 14 after the event date.

## Before the event

Check that every creator has the brief, the deliverables, a tracked link and
the data checklist from `offers/creator-visibility-offer/report-and-data.md`,
with the screen recording deadlines written into their agreement. If anything
is missing, tell Baba before the event, not after.

## Day 1

Collect Story insights and live stream analytics. Stories expire, so this
cannot wait.

## Day 2: the 48 hour check

- List every agreed post: live or not, link, time, and whether it carried
  the tag, hashtag, key message and call to action.
- Write `48-hour-check.md` (`specs/visibility-report.md`) with a chase list
  of anything missing.
- Hand it to Baba.

## Day 7

- Streamers: collect replay and clip views.
- Chase anything still missing from day 2.

## Day 14: the report

- Collect full analytics from every creator by screen recording.
- Build the report to `specs/visibility-report.md`.
- Run `REVIEW.md`.
- Hand it to Baba with a list of every field marked n/a and why.
