## A new folder

- `brief.md`: the prospect brief (`specs/prospect-brief.md`).
- The pitch pack once Baba approves the brief (`specs/pitch-pack.md`).
- One subfolder per event for reports (`specs/visibility-report.md`).

## In the first two folders

- `deck.pdf`: the eight slide pitch deck. Rendered from the deck source for
  reference, so spacing can differ slightly from the live deck. For a deck to
  send, export it from the Slides editor.
- `deck-source/`: the slide files (`project/deck.json` and one HTML file per
  slide) and the images they use (`assets/`, named by the asset id each slide
  references). Copy this to start a new deck.
- `sample-report.pdf` and `sample-report.html`: the post event report with
  fictional creators and figures. Page one says so in red.
