# AToure

Working files for AToure Management & Consulting, set up as a workspace for
AI employees. Start with `CLAUDE.md`: the house rules, the AI employees and
where everything lives.

| Folder or file | What it holds |
|---|---|
| `CLAUDE.md` | House rules, AI employee roles, and a map of the repo |
| `ROADMAP.md` | The current goal, what is next, known issues |
| `REVIEW.md` | The check every draft passes before it goes to Baba |
| `PERMISSIONS.md` | What AI employees may do alone, ask first, or never do |
| `context/` | Who we are, who buys, how we write, what we can prove |
| `customers/` | One folder per client or prospect, the pipeline status, and the government outreach tracker |
| `offers/` | The Creator Visibility Offer and the government programmes |
| `specs/` | What each deliverable must contain and what done looks like |
| `demos/` | What we show a prospect before they sign |
| `tickets/` | One file per task, one clear outcome each |
| `routines/` | Recurring work each AI employee runs |
| `tools/` | Eyes (screenshots on desktop and phone) and the copy check |
| `brand/` | The brand kit: logos, fonts, colour palette, legacy logo sources and reference files. Start with `brand/README.md` |

## Offers

- `offers/creator-visibility-offer/`: talent access, creator management on
  the ground, and the visibility report. Value proposition, how to adapt it
  by event type, the report and data specification, and the pitch playbook.
- `offers/government-programmes/`: the Programs Menu for ministries and
  tourism boards, the government case study pack, and the endorsement letter
  template.

## Customers

- `customers/pfl-africa/`: Rwanda Season Finals trial proposal and sample
  report, October 2026.
- `customers/african-mma-league/`: trial proposal and sample report, October
  2026.

## Adding something new

- A new offer: a folder in `offers/` with its own `README.md`.
- A new client or prospect: a folder in `customers/` named after them, and a
  row in `customers/README.md`.
- A new demo: a folder in `demos/`, see `demos/README.md`.
- A new task: a ticket in `tickets/`, see `tickets/README.md`.
- A new AI employee: a section in `CLAUDE.md`, a spec for what it produces,
  and a routine.
- Brand assets only ever go in `brand/`.
