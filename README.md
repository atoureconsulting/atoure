# AToure Internal Reference

This repository is the internal knowledge base for AToure Management & Consulting. It is not the public website. It exists so that anyone writing a proposal, a caption, a deck or a pitch for AToure can pull accurate, consistent facts about the company, its brand, its services, its past work and its creator network, instead of reconstructing them from memory each time.

Everything here is written in AToure's own house style: no hyphens or dashes anywhere, AToure described as a management and consulting company rather than an agency, Baba Touré referred to as Director, and figures only stated when they are verified in source material (labelled estimated or modelled where that is what they are).

## A note on figures

Do not add a view count, reach figure or impressions number to any file in this repository unless it is explicitly present in the source material referenced in that file. Where a source describes a figure as estimated, modelled or inferred, keep that label. Reach and impressions are always modelled rather than reported, since Instagram stopped exposing a separate impressions metric for Reels in 2024, and reach is always lower than views because views count replays and reach counts unique accounts. If a number is needed and cannot be verified, leave it out and ask rather than estimate.
